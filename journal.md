Haunted Tavern Development Journal
CSC 4370 WEB
Joe Turner, Shozab Mirza

We met in person to look at the options for our project and decided to make a card game website. We chose Highcard because it was very simple to help us get started. We added blackjack because it is also simple and most people understand how to play it. We added to game gwent because not many people have heard of it and it is a fairly easy to learn. We tried making the games fully playable, starting with highcard but quickly learned this was not possible. We decided to pivot and make a card game demo instead. We thought about what pages needed to be included and added those to our todo list. As we worked, new ideas would come to us and we independently could add task. We then talked about what we added and when they needed to be done during our standup meetings.

Create the rough webpage
We added the homepage, lobby, card deck, rules and game table pages. At first they were pretty empty. We worked on the initial phases while next to eachother so we could collaborate on what info needs to be on each page, the style of the page, how navigation buttons should look. This helped us have a better understanding of our website before we started working on task seperatly.

Better CSS
During the first part of creating the webpage we had some css, so we could better see how we wanted to page to look. Once we got to a place we were happy with we started working heavier on the css for things such as highcard flip animation. We would progressively add css while working on an html page but kept the heavier css coding for later. An example of a problem we faced was getting the gwent current turn animation to work the way we wanted. At first it was not clear what the animation was doing so made the boxes bigger and made the glow effect bigger. 

We saved the gwent game for last since its not a well known game and we wanted to get more comfortable with the rest of the website before we added this unknown game. This is where we added a score box, current turn indicator, show different states of cards such as selected or used (which makes the card inactive from effects and greys it out).

Testing
We tested every button we placed and made sure it linked to where we wanted it. We looked at each card to see if the animations worked everywhere. We checked the mobile view by inspecting the page and selecting the mobile view button then change the width of the screen to simulate a phone. We tested the pages by pressing tab to see if the webpage would select different elements just by using the keyboard. We ran the HTML files and CSS file through the W3C validation and fixed the few errors that came up.
