## Images, fonts and code libraries

- **Images:** none. The site uses no image files. Every card, deck and table is built with HTML and CSS.
- **Suit symbols (♠ ♥ ♣ ♦):** standard Unicode text characters, not images.
- **Fonts:** Arial, the system font. No web fonts are loaded.
- **Libraries, frameworks and scripts:** none. The site is plain HTML5 and CSS3 with no JavaScript.
- **Code references:** the HTML and CSS were written by the team. The card flip uses the common "hidden checkbox plus label" CSS technique, which needs no JavaScript.

## Game ideas and rules

- **Gwent:** our version is a simplified, original demo inspired by the Gwent card game from *The Witcher 3* by CD Projekt Red. It does not use any of their artwork, card names or text. Gwent is a trademark of CD Projekt Red.
- **High Card and Blackjack:** traditional card games. The rules are standard and in the public domain. The 52-card deck and its values are standard.
