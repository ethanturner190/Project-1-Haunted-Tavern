Team Communication

We mainly used discord to talk to each other and write about what needed to be done. We used the trello board to keep track with task, but we both got a lot of ideas in the moment while working so instead of adding every little thing to the board we would just complete the task. We would add it to the board if we couldn't get the feature done in a work session. We did a lot of work while being next to each other because it made communication and sharing ideas easier. Many task were done independently but most of the project was done together. We ran into problems early trying to get everything to work smoothly on github and found it more productive to actively work together.
